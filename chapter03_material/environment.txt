运行方式：python build_experiments.py
建议用独立Python环境，先运行 python -m pip install -r requirements.txt。
全部图表为Matplotlib计算绘图；本次中文字体：Noto Sans CJK。
其他平台可安装Noto Sans CJK、微软雅黑或黑体；也可通过CH03_FONT_PATH
指定本机中文字体文件路径。若没有可用中文字体，计算仍可执行，但图中文字可能缺失。
Notebook为nbformat 4.5。当前环境不含Jupyter内核，已分别在独立Python进程
中按顺序执行全部代码单元，并保存输出；尚未在Jupyter前端逐项试用。
Jupyter Notebook/Lab为交互打开所需的可选环境，不属于本次已安装依赖；
需要时可另行安装，例如 python -m pip install notebook。
内存统计使用可选的resource模块；Windows上该项记为null，不影响实验。
生成CSV使用两个独立种子；Notebook只读CSV，不重新划分。
